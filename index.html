Set the dates and click "Apply to all Active staff" and a leave record will be created automatically for every staff member.

Bulk Import Leave Records

Import many historical leave records at once (e.g. from an old spreadsheet)
Paste CSV data below with the header row exactly as shown, one leave record per line:
TCNo,Category,Type,Year,StartDate,Days,TicketType,Remark,GroupID
Example: 3034,Annual Leave,Annual Leave,2004,2004-07-05,48,Company Ticket,,G001
StartDate must be in YYYY-MM-DD format. TicketType, Remark, and GroupID can all be left blank. Category must be one of: Emergency, Local, Annual Leave. GroupID is optional — give several rows the same GroupID to have them appear together as one combined leave request in Leave Details (e.g. Annual + Eid Al Fitr + Unpaid taken as one trip); leave it blank for a standalone entry. All imported records are saved with status Closed (i.e. already-completed historical leave) so they count toward balances immediately.
